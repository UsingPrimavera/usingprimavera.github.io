## Overview

This Reference will show you where to find Oracle Documentation in general, and more specifically the documentation most likely to be of interest to users of Oracle Primavera, users of Oaracle Analytics Server who run and write reports using Primavera data, and also those who are interested in installing the Oracle technology stack.

[Oracle Corporation](https://www.oracle.com/) acquired [Primavera Systems Inc.](https://en.wikipedia.org/wiki/Primavera_Systems) in October 2008, and [the deal was announced by Oracle on 8 Oct 2008](https://www.oracle.com/corporate/pressrelease/oracle-buys-primavera-100808.html). Then in July 2012, [Oracle Buys Assets of Skire](https://www.oracle.com/corporate/pressrelease/oracle-buys-skire-071912.html) was announced on the Oracle Corporation web site. Skire created Unifier.

## Oracle Documentation Landing Page

Oracle make all their documentation available to anyone. The [Oracle Help Center](https://docs.oracle.com) is the landing page for all Oracle documentation. It has a search box where one can enter the name of the product, but there are other browsing options.

- The Oracle Primavera products can be found from the Oracle Help center within [Industry-Specific Applications](https://docs.oracle.com/en/industries/index.html) and then under the [Oracle Construction and Engineering](https://docs.oracle.com/en/industries/construction-engineering/index.html) section. There are 
    - [Primavera Administration Documentation](https://docs.oracle.com/en/industries/construction-engineering/primavera-administration/index.html) - used to administer P6 EPPM, P6 Professional, Primavera Unifier, Primavera Gateway, Construction Intelligence and Primavera Analytics on the cloud.
    - P6 Enterprise Project Portfolio Management (P6 EPPM) has an area for [User and Integration Documentation](https://docs.oracle.com/en/industries/construction-engineering/primavera-p6-project/index.html), and another for [Installation and Configuration Documentation for On-Premises Deployments](https://docs.oracle.com/en/industries/construction-engineering/primavera-p6-project-install/index.html).
    - [Primavera P6 Professional Documentation](https://docs.oracle.com/en/industries/construction-engineering/primavera-p6-professional/index.html).
    - [Primavera Gateway Documentation](https://docs.oracle.com/en/industries/construction-engineering/primavera-gateway/index.html).
    - [Unifier Documentation](https://docs.oracle.com/en/industries/construction-engineering/primavera-unifier/index.html).
    - [Primavera Analytics Documentation](https://docs.oracle.com/en/industries/construction-engineering/primavera-analytics/index.html).
    - On-Premises Tested Configurations for [P6 EPPM](https://docs.oracle.com/cd/F88967_01/English/tested_configurations/index.htm), [P6 Professional](https://docs.oracle.com/cd/F88968_01/English/tested_configurations/index.htm), [Gateway](https://docs.oracle.com/cd/F37377_01/English/tested_configs/index.html), [Unifier](https://docs.oracle.com/cd/F88970_01/English/tested_config/index.htm), and [Analytics](https://docs.oracle.com/cd/F90226_01/English/tested_configs/index.htm).

- [Oracle Analytics Server](https://docs.oracle.com/en/middleware/bi/analytics-server/) can be found on the Cloud Infrastructure pane or by going to [On-Premises Applications](https://docs.oracle.com/en/applications/index.html) and then browsing or searching through thr [Products A-Z](https://docs.oracle.com/en/browseall.html).  It may be worth browsing the [Guides](https://docs.oracle.com/en/middleware/bi/analytics-server/books.html), and [Videos](https://docs.oracle.com/en/middleware/bi/analytics-server/videos.html), but the following are the priority for understanding how to create and run reports.
    - [Using Oracle Analytics Publisher in Oracle Analytics Server](https://docs.oracle.com/en/middleware/bi/analytics-server/user-publisher-oas/index.html) - useful for anyone who needs to run reports.
    - [Designing and Publishing Pixel-Perfect Reports in Oracle Analytics Server](https://docs.oracle.com/en/middleware/bi/analytics-server/design-publish/index.html) - this will give you a good iea about what is possible and how to try and create reports. 
    - [REST API for Oracle Analytics Publisher in Oracle Analytics Server](https://docs.oracle.com/en/middleware/bi/analytics-server/oap_rest_api/index.html) - this API has sections to Manage Jobs and Manage Reports.

- The Oracle Database documentation covers a multitude of different perspectives, including installing, updating, backup, performance and development. Here are some of the more frequent areas of interest.
    - [SQL Language Reference](https://docs.oracle.com/en/database/oracle/oracle-database/19/sqlrf/index.html) - a complete description of the Structured Query Language (SQL) used to manage information in an Oracle Database.
    - [Database Concepts](https://docs.oracle.com/en/database/oracle/oracle-database/19/cncpt/index.html).
    - [Administrator's Reference for Linux and Unix-Based Operating Systems](https://docs.oracle.com/en/database/oracle/oracle-database/19/unxar/index.html), and [Administrator's Reference Guide for Microsoft Windows](https://docs.oracle.com/en/database/oracle/oracle-database/19/ntqrf/index.html).
    - [Database Administrators Guide](https://docs.oracle.com/en/database/oracle/oracle-database/19/admin/index.html).

- [Oracle Fusion Middleware](https://docs.oracle.com/en/middleware/) is the brand name that includes all the components required to run a full Primavera System. There is a lot in Fusion Middleware, and to give an idea of how vast it can be, the Oracle Analytics Server is just one component, but it needs others to run. 
    - [Oracle WebLogic Server](https://docs.oracle.com/en/middleware/fusion-middleware/weblogic-server/index.html) - application server used by all the Primavera products.
    - [Oracle Enterprise Manager](https://docs.oracle.com/en/enterprise-manager/index.html) - Helps manage Fusion Middleware systems.
